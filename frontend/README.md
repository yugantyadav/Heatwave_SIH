# Frontend

React + Vite + Leaflet dashboard for the Heatwave Early Warning System.

## Development

```bash
cd frontend
npm install
npm run dev
```

## Features (to be implemented)

- Interactive choropleth map of Mumbai wards
- Risk-based coloring (Low/Moderate/High/Severe)
- Ward popup with thermal indices and risk score
- 3-5 day forecast chart
- Admin panel for threshold configuration
- Twilio/WhatsApp alert integration
